# ESP32 Smart Budget Planner

An IoT-based Smart Budget Planner built using ESP32 to monitor expenses, track budgets and provide visual alerts through an OLED display and RGB LED.

## Project Overview

The ESP32 Budget Planner helps users monitor their spending by comparing expenses against a predefined budget.

## Hardware Components

- ESP32 Development Board
- OLED Display (128×64)
- RGB LED
- Potentiometer

## Key Features

- Budget and expense monitoring
- Remaining balance calculation
- Real-time OLED display
- Green LED – Budget within limit
- Yellow LED – Budget near limit
- Red LED – Budget exceeded
- Invalid input validation

## Technologies Used

- Arduino C++
- ESP32
- Wokwi Simulator
- OLED Display
- I2C Communication
